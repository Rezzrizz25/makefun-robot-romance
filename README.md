A single-line pickup line written to charm a robot or an AI — the whole punch lands in one API call, under 200 characters.

> Are you an API? Because every time I call you, my heart returns a 200 OK.

## Run it

```bash
node main.ts
```

This writes the entry line to `entry.txt` inside `$MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
